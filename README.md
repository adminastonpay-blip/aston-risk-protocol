# Aston Risk Protocol (ARP-1)

**A vendor-neutral proposal for decision risk, provenance and agent governance.**

- **Version:** 1.0.0-draft
- **Status:** Standards proposal — not ratified
- **Author attribution:** Hector Zapata / ASTON OS Initiative
- **Draft date:** 2026-11-06

## What ARP-1 proposes

ARP-1 defines a common framework for:

1. Decision records and evidence provenance.
2. The Aston Risk Rating (ARR), with explicit dimensions and scoring profiles.
3. Risk Envelopes that constrain agent and operator authority.
4. Policy outcomes: ALLOW, DENY and REQUIRE_APPROVAL.
5. Human approval, audit integrity and fail-closed execution controls.
6. Interoperable schemas and conformance levels.

ARP-1 is a proposal for technical review. It does not claim certification, regulatory compliance, independent validation or production deployment.

## Status and contributions

This is an initial public draft. Issues and pull requests are welcome for technical discussion. Please identify proposed changes by section and explain security, privacy, interoperability and operational implications.

No conformance certification program currently exists. Implementations must not claim ARP-1 conformance merely by referencing this document.
